SHANE DEDASE PORTFOLIO
======================

This is a static, responsive portfolio website.

Pages
-----
index.html   - Home / portfolio landing page
about.html   - About, skills, experience and working style
projects.html - Selected project showcase
contact.html - Contact form and contact details
resume.html  - Portfolio CV summary with a direct download link to the real PDF CV

Assets
------
The original GIF illustrations, profile image, background, and arrow asset are retained. The actual PDF CV is included as CV - DEDASE.pdf.

How to use
----------
1. Open index.html in a browser.
2. No server or database is required.
3. The contact form opens the visitor's default email application.
4. The CV buttons download the included CV - DEDASE.pdf file directly.

Customization
-------------
- Main styles: style.css
- Interactions/navigation/reveal effects: script.js
- Contact email is configured in contact.html and script.js

Notes
-----
This version removes the broken/duplicated inline CSS and replaces it with a single consistent responsive design system.


VIDEO PROJECT MEDIA
--------------------
Place these four files in the same folder as index.html and projects.html:
- defiant.png  (thumbnail)
- defiant.mp4  (video)
- hospital.png (thumbnail)
- hospital.mp4 (video)
The project cards link directly to the local MP4 files.
